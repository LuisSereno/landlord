## Ausencia de `12-multiparcel-building.png`

La captura de un complejo multi-parcela terminado no se generó. El harness completó el ensamblado
legítimo de una acería de tres solares y pulsó **Iniciar obra**, asignó una cuadrilla y activó 4×;
sin embargo, el edificio no llegó al estado terminado antes del límite de espera del harness.

No se sustituyó por un estado inyectado ni por una geometría sintética. La evidencia 11 conserva el
estado real `3/3 parcelas`; la 12 queda pendiente de diagnosticar el avance de obra y de repetir el
flujo hasta su finalización verificable.
