# D-058 — Base de presentación antes del Visual Direction Spike

Estado: Aceptada
Fecha: 2026-10-21
Alcance: WP2.11 y WP2.14

## Contexto

Una dirección visual no puede evaluarse con rigor sobre una página técnica sin jerarquía ni una
composición representativa del juego.

## Decisión

Antes del spike visual, la aplicación adopta un layout map-céntrico con HUD jerarquizado, panel
operativo superpuesto y plegable, inspector contextual y estados legibles de propiedad, obra,
selección y riesgo.

Esta decisión no fija estilo, cámara ni assets finales. Sólo define una superficie válida para
comparar direcciones visuales.

## Evidencia

`apps/web/src/App.tsx`, `apps/web/src/styles.css` y `scripts/phase2-browser-smoke.mjs`.
