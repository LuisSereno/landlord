# IP y preservación

## Estado de la referencia
Mob Rule / Street Wars continúa comercialmente disponible según el dossier y System 3 aparece como explotador actual en las fuentes revisadas.

La cadena contractual exacta entre Studio 3, System 3, Infogrames, Simon & Schuster, Kalypso y otros distribuidores no quedó completamente documentada.

## Regla de Landlord
Landlord debe ser una IP independiente.

No reutilizar:
- marcas;
- logotipos;
- personajes;
- sprites;
- mapas;
- música;
- efectos;
- voces;
- textos;
- manuales;
- interfaz;
- naming distintivo.

## Investigación válida
Sí pueden estudiarse:
- estructuras abstractas de gameplay;
- problemas de UX;
- recepción crítica;
- patrones de género;
- soluciones sistémicas.

## Preservación
El dossier distingue investigación histórica de distribución autorizada:
- demo promocional y manuales son fuentes útiles;
- la existencia de imágenes archivadas no implica permiso de redistribución;
- para jugar, las ediciones comerciales son la vía recomendada.

## Antes de comercializar
Revisión jurídica de:
- marca Landlord;
- arte;
- similitud global;
- copy;
- nombres;
- marketing;
- referencias públicas a juegos inspiradores.
