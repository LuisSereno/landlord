# Dominio del juego

## Entidades/agregados conceptuales

### Game
Tiempo, seed, mundo y economía global.

### District
Parcelas, estadísticas, servicios y población.

### Parcel
Owner, valor, zoning y building.

### Building
Type, level, state, tenants y maintenance.

### Company
Cash, assets, liabilities y reputation.

### Actor
Worker, tenant, manager, political actor o criminal.

### Faction
Resources, strategy, relationships y territory/influence.

### Government
Mayor, council, policies, budget y approval.

### Policy
Category, modifiers, support y fechas.

## Sistemas

- real estate;
- construction;
- resources;
- tenants;
- finance;
- AI;
- crime;
- police;
- politics;
- society;
- procedural world;
- progression.

## Feedback loops

Economía -> sociedad -> política -> regulación -> economía.

Crimen -> policía -> política -> crimen.

Urbanismo -> suelo -> población -> política -> urbanismo.

Empresa -> deuda -> crecimiento -> riesgo -> liquidación/oportunidad.

## Core loop

comprar
-> producir
-> construir
-> ocupar
-> cobrar
-> mejorar
-> competir
-> asumir riesgo
-> adaptarse
-> reinvertir.
